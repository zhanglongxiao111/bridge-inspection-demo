# 全局体验与底层架构提升计划 (UX & Engine Enhancement Plan)

## 0. 导言
当前系统虽然在前端视觉和 UI 状态流转上初步具备了 SaaS 级平台的雏形，但在**底层仿真引擎**、**大/小场景空间联动**以及**交互沉浸感**方面仍处于非常“简陋”的原型阶段。
本计划旨在深入复盘现有代码库，提出面向“工业级高精度数字孪生”演进的全面升级方案。

---

## 1. 🌍 宏观与微观空间联动重构 (Macro-Micro Transition)
**现状痛点**：目前“指挥中心（Cesium 地球）”和“飞行控制（Three.js 局部场景）”是两个完全割裂的独立 DOM 容器，切换时只是生硬的 CSS 隐藏与显示，毫无空间连续性。
**提升方案**：
- **地理坐标映射 (Geo-Referencing)**：建立 Cesium 经纬度 (WGS84) 与 Three.js 局部直角坐标系的矩阵转换关系。
- **无缝拉近动画 (Seamless Zoom-in)**：在指挥中心点击具体大桥节点时，触发 Cesium 相机的极致拉近动画；当视角高度降低到阈值（如 500m）时，利用 WebGL 遮罩或 Alpha 过渡，平滑溶解进入 Three.js 的高精度桥梁渲染场景。
- **反向联动**：在局部 FPV 飞行时，右上角的二维缩略图应与 Cesium 的视角保持小地图级别的同步更新。

---

## 2. 🛸 无人机仿真引擎重置 (Drone Physics & Assets)
**现状痛点**：目前无人机仅由几个 `THREE.BoxGeometry` 拼接而成，物理飞行仅靠简单的 `translateZ` 线性位移计算，毫无惯性、空气动力学和真实感。
**提升方案**：
- **高精模型替换**：引入经过减面和 Draco 压缩的真实无人机 `.glb` 静态模型（如 DJI M350 RTK），包含折叠桨叶的细节。
- **真实物理引擎 (Cannon.js / Ammo.js)**：抛弃当前的线性增量，引入刚体动力学。加入质量、阻力系数、推重比公式。按 WASD 时计算的是受力 (Force) 而非位移。
- **动态天气耦合**：
  - **风阻计算**：将系统面板上的“风速 (2.4 m/s)”与无人机的位移进行向量叠加。大风侧吹时，无人机必须自动倾斜机身 (Pitch/Roll) 进行姿态补偿。
  - **高度气压模拟**：随着飞行高度的增加，模拟更猛烈的气流抖动 (Camera Shake)。

---

## 3. 🛡️ 环境感知与交互反馈 (Environment & Collision)
**现状痛点**：当前无人机可以穿模飞跃桥墩，遇到海平面不会坠机，完全是一台“幽灵摄像机”。
**提升方案**：
- **射线检测 (Raycasting) 避障导航**：
  - 在无人机前方、上方、下方发射 3D 射线 (Octree 碰撞检测优化)。
  - 当检测到距离桥柱小于 2m 时，自动触发 `Obstacle Avoidance` 逻辑进行平滑绕行，并切断 WASD 往前的强行输入。
- **海平面物理反馈**：当无人机 `Y` 轴坐标接触到水面 (`Y=0` 以下) 时，触发坠毁逻辑。利用 Three.js 粒子系统 (Particle System) 生成溅水动画 (Water Splash) 和报错警报声。

---

## 4. 🚀 彩蛋功能：战术武装拓展 (Tactical Payload)
**现状痛点**：缺乏趣味性。
**提升方案**：
- 在系统管理界面增加“隐藏开发者模式”，激活后无人机底部挂载模块切换为“导弹发射器”。
- **交互**：在 FPV 模式下，右键瞄准锁定，左键发射。
- **视觉效果**：利用线段生成导弹轨迹，击中海面或指定病害点时播放爆炸特效碎片与火光，增强演示项目的话题性和演示震撼感。

---

## 5. 🔀 其他代码层面的重构 (Code Refactoring)
1. **动画曲线平滑化**：当前上帝视角双击切换目标时，使用的线性 `lerp` 导致镜头僵硬。需改用 `TWEEN.js` 或 `GSAP` 实现 Ease-In-Out 平滑曲线。
2. **路径可视化 (Path Line)**：目前使用尖锐的直线连接航点。需采用 `THREE.CatmullRomCurve3` 生成曲线航迹，让自动导航的飞行路线更符合空气动力学轨迹。
3. **性能优化**：水面目前是简单的透明平面，应当引入 `WaterShader` 替换现有的蓝色平面，增加海浪起伏和环境光反射，以匹配暗色主题的宏大感。
4. **架构解耦**：将当前的 `main.js` 拆分为 `Renderer.js`, `UIManager.js`, `InputController.js`，避免随着功能激增导致单文件膨胀。
